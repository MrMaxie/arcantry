<section class="lifecycle-section">
  <div class="section-intro">
    <p>Repository lifecycle</p>
    <h2>Two histories. One delivery model.</h2>
  </div>
  <div class="lifecycle-columns">
    <article>
      <span class="lifecycle-index">01 — Intent</span>
      <h3>OpenSpec records the change.</h3>
      <p>Proposal, behavior, design decisions, tasks and release-facing outcome stay together as one unit of work.</p>
      <code>change → implement → verify → archive</code>
    </article>
    <article>
      <span class="lifecycle-index">02 — Delivery</span>
      <h3>Release consumes what was delivered.</h3>
      <p>Archived changes determine SemVer impact and changelog content. Git remains the technical implementation history.</p>
      <code>archive → plan → cut → changelog</code>
    </article>
  </div>
</section>
