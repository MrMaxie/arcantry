## Repository contract

```text
intent        OpenSpec change
implementation Git commits
verification  just check
completion    OpenSpec archive
release       archived changes → SemVer + CHANGELOG.md
```

Arcantry does not infer product history from commit messages. A commit can explain a refactor precisely and still be irrelevant to a user-facing release. The archived OpenSpec change keeps the proposal, specs, design, tasks and release note together after delivery.
