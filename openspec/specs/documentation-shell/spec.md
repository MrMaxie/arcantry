# Purpose

Define the visual and interaction contract for Arcantry documentation so the published site represents the approved brand without giving up Starlight's documentation capabilities.

# Requirements

## Documentation shell matches the approved Arcantry concept

The published documentation MUST use Arcantry's approved shell rather than Starlight's default visual layout. The shell MUST include the branded left navigation, a wide top search/header region and Arcantry typography and spacing.

## Overview page preserves the approved composition

The documentation landing page MUST preserve the approved composition: editorial hero copy, six compact navigation cards and the repository lifecycle explanation as a distinct downstream section.

## Brand assets are first-class

The Arcantry mark and wordmark MUST be represented as repository-owned brand assets in the documentation UI. Text-only approximations MUST NOT replace the brand treatment where the design calls for it.

## Documentation remains operational

Search, responsive navigation, dark/light theme support and accessible content navigation MUST continue to work after the visual shell is replaced.
