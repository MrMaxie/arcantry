# Why

The documentation shell now follows the approved composition, but three brand-critical details still drift from the concept: the logo is reconstructed instead of using the approved mark, the palette introduces purple that does not exist in the concept, and the typography uses generic fallback faces.

# What changes

- Use the approved Arcantry wordmark and mark as source assets instead of recreating them with text or approximate SVG paths.
- Replace the purple palette with the neutral black / warm-white palette shown in the approved documentation concept.
- Self-host the typefaces used to match the concept: Manrope for UI/body copy and Instrument Serif for editorial headings.
- Remove the decorative hero mark that is not present in the approved overview composition.

# Out of scope

- Changing documentation information architecture.
- Adding new documentation sections.
- Changing repository lifecycle behavior.
