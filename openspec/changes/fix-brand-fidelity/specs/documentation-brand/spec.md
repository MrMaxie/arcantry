# MODIFIED Requirements

## Brand assets are canonical

The documentation MUST render the approved Arcantry wordmark and mark from repository assets. Components MUST NOT recreate the wordmark using ordinary text or substitute an approximate mark.

## Documentation palette is neutral

The light documentation theme MUST use the approved neutral warm-white, graphite and hairline-gray palette. Purple or other chromatic accents MUST NOT be introduced unless they are present in an approved concept.

## Documentation typography matches the concept

UI and body copy MUST use Manrope. Editorial display headings MUST use Instrument Serif. The fonts MUST be provided by the repository build rather than depending on a visitor's system fonts.

## Overview avoids unapproved decoration

The overview hero MUST NOT include a decorative oversized brand mark when that element is absent from the approved concept.
