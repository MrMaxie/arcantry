# Why

The overview gives the framed `Download` link an additional separator, which repeats a boundary the button already communicates. The recommended shared and private setup also leaves user-scoped skills visually inactive even though Arcantry recommends user scope as the default reusable skill location.

# What changes

- Remove the redundant separator around the framed `Download` action and add the established download icon before its label.
- Keep the download action outside the command tablist and right-aligned on supported wide viewports.
- Include user-scoped Computer skills in the default recommended shared and private setup while retaining repository-scoped skills.

# Out of scope

- Changing the GitHub Release URL or download behavior.
- Changing command tab order, copy behavior or persisted selection.
- Changing the private or selected-source presets.
- Changing product, CLI, skill or npm package versions.
