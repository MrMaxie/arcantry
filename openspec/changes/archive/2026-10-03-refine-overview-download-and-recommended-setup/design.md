# Design

The shared command picker remains the single owner for both overview and content-page installation controls. The existing framed link continues to distinguish navigation from command selection, so the separate desktop and narrow-layout divider rules are removed. The Starlight `download` icon is reused inside the link without changing its accessible name or destination.

The recommended preset remains a data-only state in `ArcantryKnowledgeGraph`. Adding `computer-skills: User` activates the existing Computer source row and exposes its existing mode label; no new row, component or interaction state is introduced.
