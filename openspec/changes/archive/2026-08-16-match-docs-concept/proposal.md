# Why

The published documentation uses Starlight's default visual shell with Arcantry colors. It does not match the approved Arcantry documentation concept and therefore does not represent the brand.

# What changes

- Replace the default documentation header and sidebar presentation with the approved Arcantry shell.
- Rebuild the overview page around the approved editorial hero, six navigation cards and lifecycle section.
- Use the approved Arcantry wordmark and mark as first-class documentation assets.
- Keep Starlight for documentation routing, search and accessibility while replacing its visible default character.
- Preserve responsive documentation navigation and light/dark theme support.

# Out of scope

- Changing the repository lifecycle model.
- Adding documentation sections for features that do not exist.
- Introducing a new UI framework or design system dependency.
