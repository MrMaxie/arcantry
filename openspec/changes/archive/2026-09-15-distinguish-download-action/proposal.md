# Why

The GitHub Release download link currently sits directly beside the command tabs with the same visual treatment. Readers can mistake it for another selectable command tab even though it navigates to a different page.

# What changes

Keep `Download` at the far right of the picker header, separate it from the command tabs with a divider, and render it as a compact secondary button-link.

# Out of scope

- Changing the available installation methods or their order.
- Changing the GitHub Release URL or download behavior.
