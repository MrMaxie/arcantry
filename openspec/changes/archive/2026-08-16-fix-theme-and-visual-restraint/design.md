# Design

Use one semantic color layer for both Starlight and Arcantry-specific components. Light and dark themes define the same tokens with different values; components do not branch on theme themselves.

The dark theme is neutral rather than chromatic: near-black background, graphite surfaces, warm light text and low-contrast gray separators. The light theme keeps the approved warm-white concept.

Visual cleanup is subtractive. Remove blur/translucency and reduce radii; do not replace them with new decorative treatments.
