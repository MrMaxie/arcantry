# Why

Agents need useful project answers without repeatedly reading policy prose. Arcantry must support project conventions while reducing infrastructure and verification overhead.

# What changes

Implement the approved practical MVP in four locally verified increments: local delivery; contextual CLI and MCP; flexible project workflows and releases; smaller implementation and outcome-led documentation.

# Out of scope

New distribution channels, a policy engine, a custom todo format, a skill dependency resolver, praise-based routing, version changes, remote settings, pushes and package publication.
