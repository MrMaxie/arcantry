# Approach

Place a source-fidelity checkpoint after the existing scope test, before the skill challenges or implements a request. The checkpoint requires source inspection, an explicit preserve/change/remove/neutralize map, transformation from the named source and a final drift comparison.

For comparison and audit copies, preserve rows and labels by default. Use the artifact's established neutral convention and exclude neutralized entries from calculations. When no convention exists, retain field types, such as numeric zero for an excluded estimate. Explicit deletion or redesign remains authoritative.

Tighten the frontmatter trigger so derived structured artifacts route to this workflow while trivial translation, calculation and private implementation-only edits do not.

# Trade-offs

Preserving excluded rows can add visual density, but in comparison and audit artifacts it protects traceability. The default is intentionally limited to that audience; explicit removal and other artifact conventions still override it.
