# Why

The audience and scope workflow protects terminology and implementation scope, but it does not make the structure of an existing artifact an explicit decision boundary. An agent can therefore interpret a reduced or derived copy as permission to rename sections, change layout, add summaries or delete entries, which breaks comparison and auditability.

# What changes

Require the audience and scope skill to treat the source artifact's structure, labels, order, formulas, styles and detail as contractual unless redesign is explicit. Comparison and audit copies preserve source entries and neutralize excluded values without including them in calculations. The skill trigger becomes specific to audience-facing artifacts, derived structured artifacts and non-trivial scope-sensitive implementation.

Add a reusable scenario and forward-test criteria for structured artifact fidelity.

# Out of scope

- Spreadsheet-specific automation or formatting tools.
- A new standalone skill for derived artifacts.
- Preventing explicit redesign, privacy-driven removal or accessibility changes.
