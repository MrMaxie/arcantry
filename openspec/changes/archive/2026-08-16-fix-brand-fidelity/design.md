# Design

The approved documentation concept is the visual source of truth.

- `src/assets/arcantry-wordmark-approved.svg` is the canonical wordmark used by the sidebar.
- `src/assets/arcantry-mark.svg` is the canonical compact mark used in utility UI and as the source for the favicon.
- Manrope is the UI/body face; Instrument Serif is limited to editorial display headings.
- The documentation remains intentionally neutral: warm-white surfaces, graphite text and low-contrast gray borders. No brand-purple token is retained.
- The Starlight theme toggle remains functional infrastructure, but both theme states currently resolve to the approved light concept rather than inventing an unapproved dark palette.
