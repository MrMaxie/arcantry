# Why

The overview shows the project knowledge model, but a first-time visitor still has to infer what Arcantry gives them, why the adoption choices matter, and how little or how much of the project can be integrated. The package-runner picker also presents the current Node-based surface as if it were the complete distribution story, and the overview lacks the project footer available in documentation navigation.

# What changes

- Rewrite the overview around concrete evaluation benefits: one source map, explicit responsibility, incremental adoption, and reviewable changes.
- Expand the with-and-without comparison and remove fragmentary command names from explanatory copy.
- Present complete integration as the recommended destination while keeping private and selective adoption available for established projects.
- Add a configuration questionnaire whose private, selective, and complete-integration presets populate individual source choices and update a graph across computer, repository, and private-per-project scopes.
- Present verified npm, pnpm, Bun, and Nub package-runner commands in one copyable picker with wrapped mobile rows.
- Restore overview-only authorship, update, license, and GitHub footer details.
- Correct the clipped descender in the hero title and rename the secondary call to action to "Adapt your project".

# Out of scope

- Adding package distribution channels beyond the verified Node package runners.
- Changing CLI behavior, repository adapters, or the current runtime requirement.
- Redesigning the shared documentation shell or documentation routes.
