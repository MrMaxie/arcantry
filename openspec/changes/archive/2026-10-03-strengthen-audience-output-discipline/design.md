# Design

The decision rule remains in `SKILL.md` because it must apply whenever the skill is loaded. Paired examples live in a separate reference because they are useful only when requirements or source material may become reader-facing content.

The reference states the audience task or source evidence before each result. Its examples avoid mandatory field sets, fixed controls and incident-specific names. Exact values and support references remain visible only when the established reader task requires them.

The canonical package version advances independently to 1.0.1. Generated catalog projections and package manifests derive from `arcantry.json`; the Arcantry product and CLI stay at 1.0.0.
